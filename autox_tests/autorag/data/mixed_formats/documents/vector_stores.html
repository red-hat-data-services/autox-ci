Vector Store Integration in AutoRAG

AutoRAG supports multiple vector store backends for storing and retrieving document embeddings. The choice of vector store affects indexing performance, query latency, and scalability.

Supported Vector Stores

  • Milvus: A high-performance vector database that supports both inline (Milvus Lite) and remote deployment modes. Milvus Lite runs embedded within the pipeline process, while remote Milvus connects to an external cluster.
  • ChromaDB: A lightweight vector store suitable for development and small-scale deployments. ChromaDB stores embeddings locally and provides simple API access.
  • PGVector: PostgreSQL extension for vector similarity search. PGVector integrates with existing PostgreSQL infrastructure and supports HNSW and IVFFlat indexing.

Embedding Models

Document chunks are embedded using models served through the OGX platform. Common embedding models include BGE-M3 for multilingual support and various sentence transformer models for English-only workloads.

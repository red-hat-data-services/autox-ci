RAG Optimization Process

The AutoRAG optimization process uses hyperparameter optimization (HPO) to find the best RAG configuration for a given document corpus and evaluation benchmark.

Search Space

The search space defines the parameters to optimize, including chunk size (128 to 2048 tokens), chunk overlap (0 to 256 tokens), chunking method (recursive or hybrid), embedding model selection, and foundation model selection.

Optimization Algorithm

AutoRAG uses Generalized Additive Models (GAM) as the primary optimization algorithm. GAM models the relationship between RAG parameters and evaluation scores, enabling efficient exploration of the search space. A random search optimizer is also available as a baseline.

Evaluation Metrics

RAG configurations are evaluated using metrics such as answer correctness, faithfulness, and context relevance. These metrics are computed using the Unitxt evaluation framework or LLM-as-a-judge approaches.

# S3 Credentials Management

During text extraction, documents are downloaded concurrently using a ThreadPoolExecutor with a maximum of 8 threads, sorted by size in descending order to avoid the straggler problem.

Credential Handling:
1. Credentials loaded from environment or parameters
2. ThreadPoolExecutor manages 8 concurrent downloads
3. Large files processed first (descending size order)
4. Failed downloads logged and reported
5. Automatic retry on transient failures

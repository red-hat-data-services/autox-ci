# S3 Storage Configuration

S3 credentials are managed through Kubernetes secrets and resolved from explicit parameters first, then environment variables (AWS_S3_ENDPOINT, AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_DEFAULT_REGION).

Configuration:
- Use S3-compatible object storage (MinIO, AWS S3, etc.)
- Configure endpoint URL for the storage service
- Set up IAM credentials
- Configure bucket policies
- Enable versioning for data protection
